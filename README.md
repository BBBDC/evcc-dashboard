# EVCC & Solar-Log Live Dashboard ⚡

Modernes, responsives Echtzeit-Dashboard für EVCC, Solar-Log, InfluxDB und manuelle Fahrzeugladungen (Cupra Tavascan Max & Cupra Raval Jona).

## 🌐 Live-Webseite
Dieses Dashboard wird automatisch über GitHub Pages bereitgestellt:
👉 **[https://bbbdc.github.io/evcc-dashboard/](https://bbbdc.github.io/evcc-dashboard/)**

## 📊 Features
- **Live-Kacheln:** PV-Erzeugung, Netzeinspeisung / Netzbezug, Hausverbrauch und Batteriespeicher
- **Fahrzeugzentrale:** Cupra Tavascan Max & Cupra Raval Jona mit Akkustand (SoC), Ladeleistung, Monats- und Jahressummen
- **Solar-Log Matrix:** Übersicht aller 17 Wechselrichter mit Live-Leistung (Pac) und Tageserträgen (DaySum)
- **Ertrag & Prognose:** Heutiger Gesamtertrag (InfluxDB) sowie Solar-Wetterprognose
- **Ladehistorie:** Automatisch synchronisierte Liste der erfassten Ladevorgänge
- **Auto-Refresh:** Automatische Datenaktualisierung mit Countdown und manuellem Sofortabruf
